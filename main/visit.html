Getting Started

Anyone can gain access to the BTU Lab. The goal of the lab is to provide a diverse and inclusive environment for makers of all types.

The BTU Lab is a general workspace that supports projects involving art, design, engineering, architecture, and technology.

Orientation

New members attend a 20-minute general orientation. It covers community expectations, safety, and equipment in the lab.

Some equipment, like the laser cutters, needs an extra orientation before it can be used.

Check the BTU Calendar for upcoming orientations, workshops, and other events.

Contact the BTU Lab

If you have questions about visiting the lab, orientations, or using equipment, contact the BTU Lab.

Email: atlasbtulab@gmail.com

Before You Visit

Some tools need extra training. Make sure you complete the required orientation before using equipment for the first time.
