Quick Information

The Wood Shop is part of the BTU Lab and provides tools for woodworking and building projects.

About the Wood Shop

The BTU Lab Wood Shop gives students a place to work on projects involving wood and other materials.

Students can use different hand tools and power tools to build, cut, sand, and shape materials.

Equipment

The Wood Shop has different tools available for woodworking projects.

  • Saws
  • Drills and drivers
  • Sanders
  • Chisels
  • Files
  • Measuring tools
  • Clamps
  • Other hand tools

Orientation

Students may need to complete an orientation before using certain tools in the Wood Shop.

Orientation helps students learn how to use the equipment correctly and safely.

Safety

Always follow the BTU Lab's safety rules when using the Wood Shop.

Do not use equipment that you have not been trained to use.

Need Help?

Ask BTU Lab staff if you have questions about a tool or are unsure how to use equipment safely.
